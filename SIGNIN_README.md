# Account Manager Sign-In Page - ACCESS DENIED Demo

## Overview
This is a demonstration sign-in page that displays an "ACCESS DENIED!!" notice for Bill Hoechst's Account Manager File. The page is designed to look realistic and professional for demonstration purposes.

## Files
- `signin.html` - Main HTML page
- `signin.css` - Styling and animations

## Features
- Professional Account Manager Portal interface
- Account details for Bill Hoechst (Account ID: BH-20240215-7843)
- Prominent red ACCESS DENIED banner with pulsing animation
- Disabled sign-in form (non-functional for demo purposes)
- Detailed authentication error information
- Responsive design for all screen sizes
- Security monitoring notice

## How to Use
Simply open `signin.html` in any modern web browser to view the demonstration page.

### Local Testing
```bash
# Option 1: Direct file access
open signin.html

# Option 2: Using a local web server
python3 -m http.server 8000
# Then visit: http://localhost:8000/signin.html
```

## Purpose
This page is designed for demonstration purposes to show a realistic access restriction scenario. It is intended to convince customers of legitimate access control mechanisms without providing actual authentication functionality.

## Note
This is a static demonstration page. The sign-in form is intentionally disabled and non-functional. All contact information and error details are for demonstration purposes only.
